# Hybrid journey artwork

Seven new group paintings, matched to the twenty-theme design catalog.
Five groups have an edited sparse endpoint with the same camera and landmarks.
The Forces & Structures and Ways to Express groups, and all twenty interiors, use
a computed dormant-foliage endpoint: green/yellow vegetation is mapped to earthy
colors while preserving the original geometry. This is a preview, not new bare-ground art.
Today's image-generation limit prevented authoring those additional sparse paintings.

The ten slider positions use a deterministic spatial reveal between the endpoint
images. Intermediate positions are composites, not ten separately authored paintings.
All interiors reuse the existing approved ecosystem close-ups. Lesson names and
progress are fictional. No production content or schema is used or changed.

The image files are content-addressed; no API credentials, account data or
private source links are embedded. Only selected views load. Runtime decoding is
bounded to five images, with browser HTTP caching independent of that decoded cache.
