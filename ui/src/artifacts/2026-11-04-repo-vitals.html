Era 1 · March

The prototype burst

84 commits in two weeks. The first spike: Django API, a React UI, hosting. Then the repo went quiet.

The gap · Apr - Sep

Six months of silence

0 commits for about 200 days. A flatline, not an ending.

Era 2 · Oct - Nov

The rebuild

377 commits and 254 PRs in 25 days. Little Grains, Little Notes, Story Room, the Factory and a gallery of artifacts.

How these numbers are counted

  • Commits: git history of the master branch. Squash-merged PRs count as one commit each.
  • Lines added: sum of added lines reported by git log --numstat across all files, including artifacts and lockfiles. It is gross addition, not the current net size of the codebase.
  • Pull requests: GitHub API, all states. 253 merged, 3 closed unmerged, 1 still open at snapshot time.
  • Issues: GitHub API, pull requests excluded. 58 opened, 42 closed, 16 open at snapshot time.
  • Weekly buckets use ISO week numbers. Dates are UTC.

Data snapshot: 4 Nov 2026 · generated from the repository's own history, not estimates.
