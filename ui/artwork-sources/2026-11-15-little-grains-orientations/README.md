# Little Grains artwork archive

Preserved generated originals from the orientation study. This directory is
outside `public/`, is not imported, and does not add downloads to the working
example. The demo still offers **Ocean and Nature only**.

- [Biology](biology-portrait.png)

These are completed outputs from the broader batch before the scope was reduced.
They retain their native dimensions and baked cream paper. They have not been
integrated or approved individually.

The four RGBA sources can regenerate the example's lossless WebP/dormant pairs
using `ui/scripts/artifacts/little-grains-orientations/prepare_artwork.py`.
All twelve generated PNG outputs are preserved; no images were regenerated to
create this archive. The superseded computed dormant variants are omitted since
they are reproducible derivatives, not generated artwork.

The native dimensions remain below the original 1200px short-side production
target. `generation-prompts.json` records the completed broader-batch prompts;
the integrated pair prompts are in the example's `prompts.json`.
