{{ title }}

Upload a ZIP containing data.csv at the root and an images/ folder:

recipes.zip
├── data.csv
└── images/
    ├── 1.jpg
    └── 2.jpg

Use one row per recipe with these four columns (all headers are required):

  • title: required, up to 200 characters.
  • source_url: optional recipe link.
  • image: optional filename, for example 1.jpg, from the images folder. JPEG, PNG and WebP are supported.
  • ingredients: a JSON list of 1–100 ingredients, each with a name and optional quantity:
    [{"name":"tomato","quantity":"200 g"},{"name":"salt"}]

Download example CSV. Save the CSV as UTF-8. Spreadsheet editors handle the quoting of the JSON column when exporting CSV.

A batch creates new recipes and reuses existing ingredient names. Importing the same ZIP again creates another copy of its recipes. The entire batch is validated before saving; a failed import creates no recipes.

Limits: 500 recipes, 500 MiB ZIP, 1 GiB uncompressed, 2 MiB CSV. Each image uses the configured image upload limit (5 MiB by default).
