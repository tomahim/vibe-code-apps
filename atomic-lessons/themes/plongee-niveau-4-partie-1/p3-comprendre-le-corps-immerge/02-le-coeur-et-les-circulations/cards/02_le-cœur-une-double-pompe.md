Le cœur est principalement constitué du myocarde, un muscle gros comme le poing. Situé entre les deux poumons, dans un espace appelé médiastin, son rôle est de faire circuler le sang dans les vaisseaux.

Il se compose de deux pompes : le cœur droit et le cœur gauche. Chacune contient deux cavités - les oreillettes et les ventricules - séparées par des valvules dont le rôle est d'éviter le reflux sanguin vers les oreillettes pendant la contraction ventriculaire.

Les veines caves inférieure et supérieure acheminent le sang chargé en CO2 dans le cœur droit, qui le renvoie aux poumons par les artères pulmonaires. Les veines pulmonaires amènent au cœur gauche un sang riche en oxygène - le sang hématosé - transmis à tout l'organisme via l'aorte.
