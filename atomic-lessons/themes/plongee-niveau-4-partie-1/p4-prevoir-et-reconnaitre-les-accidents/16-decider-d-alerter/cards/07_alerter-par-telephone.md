Par téléphone à terre (CROSS 196, SAMU 15), le message comprend :

- le lieu précis ;
- le numéro de téléphone depuis lequel vous appelez ;
- le nombre de victimes ;
- les signes de l'accident (symptômes) ;
- les secours déjà apportés.

Là encore, ne raccrochez jamais le premier : restez en communication avec les secours jusqu'à ce qu'ils vous disent de raccrocher.
