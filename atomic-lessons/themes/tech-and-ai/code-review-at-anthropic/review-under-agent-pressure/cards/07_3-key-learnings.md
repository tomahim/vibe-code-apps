Agent-written code breaks the economics of manual review. When a repository goes from thousands to tens of thousands of changes a day, asking a person to read every line stops being a standard and becomes a fantasy, so the process has to change shape.

The useful question is not whether a human read the code but what could go wrong and which check, automated or human, is best placed to catch it. Review moved from a gate at the end to a continuous spellcheck, with machines reading first and people spending attention where risk lives.

The direction is proven by guardrails, not vibes. Anthropic roughly doubled merged pull requests from June to September while cutting the revert share by more than 40 percent, and the explicit target is the least human review time that keeps reverts and incidents from rising.
