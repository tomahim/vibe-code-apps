title: Every finding gets an answer
archived: false
---
The rule that every finding must be answered is what keeps the reviewer's output from becoming noise that accumulates. There are only two acceptable resolutions: fix it, or resolve the thread with a reason. Dismissing without a reason is not an option, which forces false positives to be named as such.

Those resolutions are data. Because every comment ends in a fix or a stated reason, the team can later sort every comment by how the person responded: fixed, wrong, intentional behavior, or did not matter. That classification feeds the noise measurement covered in the lesson on making the reviewer better. In other words, the discipline expected from authors is exactly what makes the reviewer improve. A review culture where findings can be ignored is one where the reviewer never learns which of its instincts were wrong.
