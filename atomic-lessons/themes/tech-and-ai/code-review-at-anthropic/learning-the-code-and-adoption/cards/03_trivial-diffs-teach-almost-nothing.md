title: Trivial diffs teach almost nothing
archived: false

The traditional objection is that skipping the reading loses the learning. The team answers with a comparison of what actually teaches. Reading trivial diffs line by line teaches almost nothing: a one-line copy change carries no transferable understanding.

An explainer for the module you are about to change teaches a lot, because the knowledge arrives exactly when it is needed and exactly at the depth the work requires. Learning researchers would call this just-in-time over just-in-case, and the codebase version favors it strongly, since the half-life of remembered detail about untouched code is short. Their culture of working in open Slack channels helps too, because you see what others are building while they build it, which keeps ambient awareness alive without mandatory diff reading.
