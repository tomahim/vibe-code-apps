The public product stays conservative: Code Review's announcement says approving a pull request is still a human call, and the product posts findings, not approvals. Anthropic's own repositories go further, letting owners decide which low-risk changes merge on automated checks alone, and the article says that line keeps moving.

The feedback loop behind the movement is the one from the earlier lessons. When a review misses something, the team asks what the model did not have in front of it and puts the fix into a CLAUDE.md, a skill, or a new check. The stated goal has not changed: less human time per change, and no more reverts than before. The team closes by asking teams that let agents open pull requests which checks they have automated, which still need a person, and what they think Anthropic has wrong, a fitting end for a process built on scored feedback.
