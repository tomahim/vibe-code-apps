title: An agent's approval never counts
archived: false
---
One rule is absolute: an agent's approval never counts as a person's. Automated review can clear a low-risk change on its own, but it cannot fill a slot that calls for a human. If the tier says one person, one person must approve, no matter how green the bots are.

Just as important, whoever prompted the change is on the hook for it. On an agent-written pull request, the person directing the agent counts as one of the required reviewers, exactly as if they had typed the code themselves. This closes a loophole that would otherwise gut the whole system: an engineer cannot launder responsibility through an agent and claim distance from the result. The person who aimed the agent owns what it produced, and that ownership is what the approval records.
