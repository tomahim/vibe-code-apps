title: "A prompt is a starting point"
archived: false
---
A prompt supplies the text and instructions the model can use as context. The model continues from that context rather than starting with a finished answer.

Imagine typing “The cat slept on the” and asking for a continuation. The model sees those words and any instruction such as “finish this as a bedtime story.” It does not first create a hidden, fully written story and then reveal it. The next piece is chosen from the context available at that instant. If you change “bedtime story” to “veterinary report,” the same opening can lead to a very different continuation. The prompt therefore shapes both the topic and the style of what follows.
