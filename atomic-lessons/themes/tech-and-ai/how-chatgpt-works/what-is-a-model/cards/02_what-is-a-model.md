Wolfram uses falling objects to show how a model can estimate a value between observations. The example is an analogy for prediction, not a language-model algorithm.

The falling-ball example strips away most of language's complexity so we can focus on prediction beyond observations. If we have measurements from a few heights, we can compare candidate rules for the gaps between them. Physics offers known laws, but the essay first treats the exercise as if we only had data. The analogy does not mean ChatGPT calculates gravity equations when choosing words. It shows why we need a model rather than an endless list of remembered answers.
