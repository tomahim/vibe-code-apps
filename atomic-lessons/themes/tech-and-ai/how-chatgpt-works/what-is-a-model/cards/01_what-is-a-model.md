title: "A table versus a rule"
archived: false
---
A table records answers already measured, while a model gives a procedure for estimating new answers. The procedure has a chosen structure.

A table might list the measured travel time for a ball dropped from floors 1, 2, and 3. If you ask about floor 2.5, the table alone has no entry. A model gives a rule for making an estimate, such as a mathematical curve fitted to the measured points. The rule may be simple or complex, but it is an explicit choice. In language modeling, the “table” would be a huge collection of observed phrases; the model instead computes a prediction for new contexts.
