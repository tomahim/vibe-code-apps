Treat generated prose as a useful proposal that may need verification. Ask for sources, use appropriate tools, and check consequential claims.

Use the model to draft, explain, compare, and explore, then choose checks that fit the claim. For a historical date, consult a source; for a numerical result, run the calculation; for a code change, execute relevant tests. If the task is creative, multiple plausible continuations can be an advantage. If the task is factual, a confident tone is insufficient. This practical model of use follows the whole path: generation is probabilistic, training provides patterns, prompting steers the current answer, and external evidence establishes what the answer can be trusted to say.
