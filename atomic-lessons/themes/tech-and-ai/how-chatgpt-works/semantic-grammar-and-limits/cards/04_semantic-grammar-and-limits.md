title: "When calculation matters"
archived: false
---
A tool can perform an explicit calculation or retrieve checkable evidence. Such work can ground an answer that text prediction alone might only make plausible.

If a question asks for the sum of invoice lines, an exact calculator or spreadsheet formula can perform the arithmetic and expose intermediate values. A language model can help translate the request, explain the result, or catch an odd input, but it should not substitute a plausible-looking total for the calculation. The same principle applies to code execution and fact retrieval. Tools expand what an assistant can do reliably when their inputs and outputs are checked. Their presence does not remove the need for judgment about whether the chosen tool fits the question.
