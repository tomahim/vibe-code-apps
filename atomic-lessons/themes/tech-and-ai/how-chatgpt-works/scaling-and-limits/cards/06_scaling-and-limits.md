title: "Where tools can help"
archived: false
---
A calculator, interpreter, or other tool can carry out explicit computation and return a checkable result. Tool use changes what an assistant can reliably do.

A calculator can return the exact product of two large integers; an interpreter can run a program; a database query can retrieve a record. If an assistant uses one of these tools correctly and reports the result, its answer can be grounded in a process beyond text prediction. Tool output still needs interpretation and may be wrong if the input was wrong or the tool was misused. The advantage is that the key step is explicit and checkable. For important questions, ask what was computed or sourced rather than relying on a smooth explanation.
