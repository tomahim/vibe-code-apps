**1. Bigger is a testable improvement, not a universal guarantee.** More capacity may make text generation better while leaving a particular exact task unreliable. Evaluate the task directly instead of inferring correctness from fluent prose.

**2. Prediction differs from execution.** A model can describe how multiplication works and still miss a new product. Wolfram's irreducibility argument highlights cases where following the required steps is essential to know the outcome.

**3. Checkable tools can close the gap.** A calculator or interpreter performs the explicit work, and a person can inspect the input and result. The assistant can then explain the verified output rather than merely offering a plausible-looking answer.
