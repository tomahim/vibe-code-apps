title: "Why some tasks need steps"
archived: false
---
Exact arithmetic and program execution can require a definite procedure. A prediction from patterns is not a substitute for verifying the computation.

Consider adding a long column of numbers. A plausible-looking total can be generated from language patterns, but a reliable result requires carrying the digits or using a calculator and checking the input. The same applies to running code: its behavior depends on each operation and the actual environment. A model may describe what a program likely does, but the description is not execution. When correctness matters, use a procedure that can be inspected or rerun, then have the assistant explain the verified result.
