Useful examples must be collected and prepared for the learning objective. Data quality and coverage affect the result.

Imagine teaching a digit model with only neat printed numbers, then testing it on shaky handwritten notes. The training data did not cover the intended situation, so weak performance would be unsurprising. Preparing data includes selecting examples, checking labels where they exist, and representing inputs consistently. For text models, large collections contain repeated, low-quality, and contradictory material as well as useful examples. More data is not automatically better if it adds the wrong patterns. Dataset choices shape what the model can learn and what it may reproduce.
