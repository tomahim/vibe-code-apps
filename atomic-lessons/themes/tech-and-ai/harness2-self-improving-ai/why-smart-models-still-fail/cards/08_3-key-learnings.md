title: 3 key learnings
archived: false
---


**1. An agent is a model plus a harness**: the intelligence comes from the model, but instructions, tools, memory and procedures decide how well that intelligence is applied.

**2. Many agent failures are organizational, not intellectual.** Reading the wrong files, choosing the wrong tool or forgetting a constraint will not be fixed by a bigger model alone.

**3. Harness² improves the system around a frozen model**, using evidence from the agent's own executions, through two recursions: one for the current task, one for getting better at improving across tasks.
