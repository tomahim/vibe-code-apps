The replacement for a score is the behavioral contrast. Run the current harness and a candidate on the same task under matched conditions, then compare what they did: which files were opened, which checks were run, what the deliverable contains. If the reference run never opened the configuration file and the candidate did, that difference is real evidence about the edit, obtained with zero knowledge of the correct final answer.

An everyday comparison helps. Imagine two cooks following the same recipe while you cannot taste the dish. You can still watch how they work. One never reads the allergy note on the order; the other reads it, tastes as they go and checks the oven temperature. You have learned something genuine about their methods without ever judging the food. Harness² systematizes exactly this kind of observation and uses it to steer every edit.
