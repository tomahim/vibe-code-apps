Behavioral contrasts are genuinely informative about procedure. They can show that an edit mitigated the targeted deficiency: the agent now inventories inputs before analyzing, or reopens its output files. They can show the edit changed nothing relevant: the same steps in the same order. And they can reveal regressions: the candidate now loops on a tool call, or skips a section it used to write.

Contrasts also power the case-study wins. The base run of the producers task never reconciled figures across files and never reopened written outputs; the improved harness did both, and the score jumped from 43.1 to 77.8. Note the direction of inference: the procedural fixes were adopted because the contrasts supported them, and the benchmark score confirmed the choice afterward. In deployment, only the first half of that sentence exists, which is why the next card's caution matters so much.
