WannaCry used a flaw in an old Windows file-sharing protocol called SMBv1. Microsoft had released a security update in March 2017, two months before the attack. The NAO reports that NHS Digital had sent alerts about the patch to NHS organisations in March and April, and that most affected machines were running Windows 7 that had not been patched.

So there was a fix available before the attack. Machines that had installed the update were protected from the spreading mechanism. Machines that had not, for example because they ran unsupported versions of Windows or because patching was delayed, were exposed. For defenders this meant that routine patching was the main protection.
