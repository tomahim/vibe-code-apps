1. Keep an inventory of the components you use. Knowing which libraries and versions run where turns a crisis into a quick search.

2. Treat all external data as untrusted, including data that is only logged. Features that interpret input need strict limits and safe defaults.

3. Support the open-source projects you depend on, and plan for vulnerabilities that may last for years.
This lesson is about a vulnerability and its mass exploitation, not a single attributed operation.
