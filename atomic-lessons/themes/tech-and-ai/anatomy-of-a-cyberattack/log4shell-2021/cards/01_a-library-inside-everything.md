Log4j is a popular open-source Java library that applications use to record log messages, the diary of what a program is doing. It is an Apache open-source project, and it is embedded in countless products, from enterprise software and cloud services to games. Many organisations did not even know they used it, since it often arrives inside another product.

On 10 December 2021, according to CISA, a serious vulnerability was disclosed in this library, quickly nicknamed Log4Shell. CISA says it affected versions 2.0-beta9 to 2.14.1, and Apache rated it critical.

Because the library often arrived inside other products, ownership of the fix was unclear. That is the practical reason this case is taught: before any patch can be applied, an organisation has to know that the component exists in its systems at all.
