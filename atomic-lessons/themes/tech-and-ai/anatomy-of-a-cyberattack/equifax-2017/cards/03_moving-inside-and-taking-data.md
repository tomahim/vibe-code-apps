After the first access in mid-May, the intruders moved through the network. According to the GAO and the House committee, they installed web shells and found an unencrypted file of credentials, which let them reach 48 databases. The House report counts about 9,000 queries.

The compromised web application could reach sensitive databases. A defender's chance of catching this comes from watching traffic leaving the network, and that is where the next failure appears.

The practical defence is layered. Store credentials in a secrets manager instead of files, give each application access only to the databases it needs, and alert on unusual volumes of queries. Each layer would have made the attackers' work slower and easier to notice.
