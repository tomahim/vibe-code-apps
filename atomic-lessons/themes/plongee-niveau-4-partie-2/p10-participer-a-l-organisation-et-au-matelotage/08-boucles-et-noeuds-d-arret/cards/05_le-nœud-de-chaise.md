title: Le nœud de chaise

---
Selon le manuel (p. 397), le nœud de chaise est un nœud essentiel, valable dans de nombreuses circonstances.

Il n'offre que des avantages : il est sûr, tout en se défaisant facilement.

C'est le nœud de boucle de référence : la leçon précédente sur les nœuds d'ajout montre d'ailleurs que le nœud d'agui est constitué de deux nœuds de chaise.
