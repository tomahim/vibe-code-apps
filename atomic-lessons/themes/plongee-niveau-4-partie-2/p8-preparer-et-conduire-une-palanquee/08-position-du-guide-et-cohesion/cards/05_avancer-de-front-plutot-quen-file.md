title: Avancer de front plutôt qu'en file
archived: false
---
Dans les eaux troubles, le manuel recommande que les plongeurs restent groupés : mieux vaut avancer de front, les uns à côté des autres, plutôt que l'un derrière l'autre.

En file indienne, chacun ne voit que le devant de palmes du précédent ; de front, l'attention mutuelle est possible.
