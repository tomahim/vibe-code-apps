title: Le long d'un tombant
archived: false
---
L'orientation le long d'un tombant est simple : parcourez le tombant dans un sens, « main gauche » par exemple, et revenez dans l'autre, « main droite », généralement à plus faible profondeur, pour adopter un profil correct.

Le soleil peut être un point de repère supplémentaire.
