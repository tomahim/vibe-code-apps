Selon le manuel, les cnidaires (« animaux-orties ») regroupent :

- les hydraires ;
- les méduses ;
- les gorgones ;
- les pennatules (plumes de mer) ;
- les anémones ;
- les alcyonaires (« coraux mous ») ;
- les coraux durs (madréporaires).
