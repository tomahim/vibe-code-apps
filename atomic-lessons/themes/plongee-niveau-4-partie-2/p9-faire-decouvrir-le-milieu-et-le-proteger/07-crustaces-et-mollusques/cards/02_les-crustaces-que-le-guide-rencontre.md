title: Les crustacés que le guide rencontre

---
Le manuel illustre les crustacés par des espèces bien connues des plongeurs :

- les langoustes ;
- les homards ;
- les araignées de mer ;
- les crabes ;
- le bernard-l'hermite ;
- les crevettes.

Sur un fond rocheux, fouiller du regard les anfractuosités, refuges de choix selon le livre, est souvent la clé pour les repérer.
