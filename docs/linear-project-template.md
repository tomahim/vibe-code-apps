# Linear project template

Suggestion for future projects, created only on request.

## Project

Name = idea name. Description = Goal (1-2 lines), Main user stories (2-3), Approach/order, Out of scope, link to the idea file.

## Issue (one per feature spec)

Goal, User story, Spec bullets, Acceptance criteria checklist, Depends on, Out of scope. Label Feature.

## Priorities

Linear has no P-levels; native scale is Urgent / High / Medium / Low.

- **P1 = High**: the next thing to build. Small, shippable standalone. One or two at a time.
- **P2 = Medium**: the next step once P1 is done. Link it with "blocked by" when sequential.
- **P3 = Low**: planned later or nice to have.
- **Urgent**: reserved for real incidents or deadlines.
- **No priority**: unsorted.

## States

Project Backlog -> In Progress when the first P1 starts. Optional milestones: "Day 1 PoC", "Month 1 MVP".
